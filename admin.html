글을 쓰고 고치는 곳이에요. GitHub 토큰으로 연결하면 이 브라우저에서 바로 저장할 수 있어요.

토큰은 어떻게 만들까요?
  1. 새 토큰 만들기를 엽니다.
  2. Repository access에서 Only select repositories → xirown.github.io를 고릅니다.
  3. Permissions → Repository permissions → Contents를 Read and write로 바꿉니다.
  4. Generate token을 누르고, 나온 값을 위 칸에 붙여 넣습니다.

클래식 토큰을 쓴다면 repo 권한만 있으면 돼요. 토큰은 다른 사람에게 보여 주지 마세요.

또는

토큰은 이 브라우저에만 저장되고, GitHub 외의 곳으로 보내지 않아요.

    공개

      검색 등록 인증 코드

      index.html <head>

      인증 코드는 index.html 의 <head> 에 <meta> 태그로 들어가요. 칸을 비우고 저장하면 태그가 지워집니다. 구글·네이버 콘솔에서 발급한 content 값만 붙여 넣으세요.

      방문자 통계 (GoatCounter)

      index.html · post.html

      GoatCounter 에서 만든 사이트 코드를 넣고 저장하면 index.html 과 post.html 에 가벼운 방문자 카운터 스크립트가 들어가요. 비우면 빠집니다. 무료로 시작하기 (1분)
